# 붕어빵 타이쿤 (cnation-bb)

포장마차에서 붕어빵을 구워 동물 손님들에게 파는 모바일 웹 게임입니다. 빌드 과정 없이 `index.html`만 열면 바로 실행됩니다.

## 플레이 방법
1. **반죽**을 들고 빈 틀을 눌러 반죽을 붓습니다. (반죽 1회 재료비 300원)
2. **팥**을 들고 반죽 위를 눌러 팥을 올립니다.
3. **꼬챙이**로 눌러 뒤집고, 한쪽이 익어 "뒤집어요!"가 뜨면 한 번 더 뒤집습니다.
4. "다 익었어요!"가 뜨면 꼬챙이로 눌러 **봉투**에 담습니다. 너무 오래 두면 탑니다.
5. 손님이 주문한 개수 이상이 봉투에 있으면 봉투를 눌러 건넵니다. 손님이 오래 기다리기 전에 건네면 팁을 받습니다.

하루 장사는 3분이며, 아침 → 노을 → 밤으로 갈수록 붕어빵은 빨리 익고 손님은 덜 기다립니다. 장사가 끝나면 매출·팁·재료비·순이익을 정산하고 최고 기록을 저장합니다.

## 실행
- 로컬: 폴더에서 `python3 -m http.server` 실행 후 http://localhost:8000 접속
- 배포: Vercel·GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다 (빌드 명령 없음).

## 파일 구성
- `index.html` · `style.css` · `game.js`: 게임 전체 (외부 라이브러리 없음)
- `assets/sprites/`: 스프라이트 (손님 9종과 화난 표정, 붕어빵 굽기 단계, 도구, 봉투, 하늘 배경 등)
- `assets/sounds/`: 배경음악 2곡(시작 화면·장사 중)과 효과음 10종
