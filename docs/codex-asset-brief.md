# cnation 붕어빵 타이쿤: 이미지 에셋 교체 작업 지침서 (Codex용)

> 이 문서는 Codex가 `cnation-bb` 저장소의 이미지 에셋을 **cnation 고유 스타일로 새로 그려서 교체**할 때 따르는 작업 지침입니다.
> 게임 로직과 다른 에셋은 그대로 둡니다. 배경음악은 이 작업 범위가 아닙니다(사용자가 직접 교체).

---

## 0. 먼저 읽을 것 (필수 원칙)

1. **새로 창작한다. 따라 그리지 않는다.**
   - 현재 저장소의 이미지는 외부에서 가져온 공개 에셋이고, 이번 작업의 목적은 **그 흔적을 없애고 cnation만의 그림으로 바꾸는 것**입니다.
   - 기존 이미지는 **크기, 비율, 기준점(어디에 닿아야 하는지), 상태 구분**을 확인하는 용도로만 참고합니다.
   - 기존 이미지를 입력(image-to-image)으로 넣어 화풍만 바꾸거나, 따라 그리거나, 같은 구도·소품·의상을 재현하지 마세요. 특히 **손님 캐릭터는 종·의상·소품을 새로 디자인**합니다(3-B 참고).
2. **파일 이름과 경로를 바꾸지 않는다.** `assets/sprites/<같은 이름>.png`에 그대로 덮어씁니다. 그래야 코드를 거의 고치지 않아도 됩니다. 예외는 손님 캐릭터 이름을 새로 정할 때뿐입니다(4장).
3. **같은 묶음은 같은 캔버스로 그린다.** 봉투 4장, 손님별 평소/화난 표정 2장은 캔버스 크기와 대상의 위치가 **완전히 같아야** 합니다. 화면에서 그림이 바뀔 때 위치가 튀면 안 됩니다.
4. **진짜 투명 배경(알파 채널) PNG로 저장한다.** 흰 배경, 가짜 체커보드 무늬, 테두리 흰 번짐(halo)이 있으면 안 됩니다.
5. **이미지 안에 글자를 넣지 않는다.** 예외는 봉투에 찍는 cnation 로고 하나뿐입니다(3-A). 게임 제목 같은 글자는 HTML로 표시됩니다.
6. 원본 이미지를 `_original/` 같은 폴더에 **복사해 두지 마세요.** 원본은 git 기록에 남아 있습니다.

## 2. 작업 순서

여러 장을 한 번에 그리면 화풍이 흔들립니다. **아래 순서대로, 단계마다 사용자 확인을 받고** 진행하세요.

1. **스타일 고정 시트 만들기.** `bread.png`(마스코트 붕어빵) 1장과 손님 1명의 평소 표정 1장을 먼저 그립니다. 사용자가 승인하면 이 두 장이 이후 모든 그림의 **화풍 기준**이 됩니다.
2. **1순위 묶음:** `bread.png` → `icon.png` → `curtain.png` → `bag0~3.png` → `start-scene.png`
3. **2순위 묶음:** 손님 캐릭터 (4장 표 작성 → 승인 → 평소 표정 전부 → 화난 표정 전부)
4. **(선택) 3순위:** 철판 위 굽기 단계 8장 (3-C)
5. **검사하기** (5장의 스크립트와 화면 확인)
6. **`CREDITS.md` 갱신** (6장)

이미지를 생성할 때는 **같은 묶음 안에서 같은 프롬프트 뼈대**(스타일 문구 + 캔버스 조건)를 쓰고 대상 설명만 바꾸세요. 생성 도구가 지원하면 1단계에서 승인된 그림을 **스타일 참고 이미지**로 함께 넣으세요. 기존 저장소 이미지는 넣지 마세요.

## 3. 교체할 파일 상세 규격

좌표와 크기의 기준은 게임 화면 **360×640**입니다. 실제 기기에서는 이 화면 전체가 비율을 유지한 채 확대·축소됩니다. 선명하게 보이도록 **표시 크기의 약 3배 해상도**로 그려 주세요.

### 3-A. 1순위: cnation의 첫인상

#### `bread.png`: 시작 화면 로고 붕어빵
- 표시 위치: 시작 화면 맨 위 가운데, **가로 150px**로 표시됩니다(세로는 비율대로).
- 캔버스: **706×544** 투명 PNG (현재 353×272와 같은 비율의 2배).
- 내용: cnation 마스코트 같은 붕어빵 1마리. 대각선 위를 바라보는 활기찬 느낌이면 좋습니다. 그림자는 코드에서 넣어 주므로 **바닥 그림자는 그리지 마세요.**
- 여백: 사방 4% 정도.

#### `icon.png`: 브라우저 탭 · 홈 화면 아이콘
- 캔버스: **512×512 정사각형**. 현재 파일은 비율이 맞지 않으니 반드시 정사각형으로 그리세요.
- **배경을 채우세요(불투명).** iPhone 홈 화면 아이콘은 투명 부분이 검게 보입니다.
- 내용: `bread.png` 마스코트를 단순화한 얼굴이나 전신, 배경은 브랜드 색. 16px로 줄여도 알아볼 수 있게 **세부 묘사를 줄이세요.**
- 중요한 요소는 가운데 80% 안에 두세요(모서리가 둥글게 잘립니다).

#### `curtain.png`: 화면 맨 위 포장마차 차양
- 표시: 화면 맨 위에 **372×64px**로 늘려서 표시됩니다.
- 캔버스: **1116×192** 투명 PNG. 현재 파일(381×133)은 비율이 달라 찌그러져 보이니, 이 비율에 정확히 맞춰 그리세요.
- 내용: 가로로 이어지는 줄무늬 천 차양, 아랫단은 물결이나 술 장식. cnation 브랜드 색을 쓰세요.
- 천 아래쪽(물결 사이)은 투명. 좌우 끝은 화면 밖으로 3px씩 나가니 **양 끝에 중요한 무늬를 두지 마세요.**

#### `bag0.png` · `bag1.png` · `bag2.png` · `bag3.png`: 붕어빵 봉투
- 표시: 화면 왼쪽 아래, **세로 80px**로 표시됩니다(가로는 비율대로). 아래쪽이 기준입니다.
- 캔버스: **4장 모두 520×560** 투명 PNG. **봉투 몸통의 위치·크기·모양이 4장에서 완전히 같아야** 합니다.
- 상태:
  | 파일 | 봉투 안 붕어빵 |
  |---|---|
  | `bag0.png` | 빈 봉투 (입구가 살짝 벌어짐) |
  | `bag1.png` | 붕어빵 1개가 입구 위로 보임 |
  | `bag2.png` | 2개 |
  | `bag3.png` | 3개 이상 (가득 찬 느낌) |
- 봉투 앞면 가운데에 **cnation 로고 도장**을 넣으세요. 로고 파일이 있으면 그 모양을 그대로 쓰고, AI가 글자를 지어내지 않게 하세요. 로고 파일이 없으면 글자 없는 심볼로 대신하세요.
- 봉투 오른쪽 위에는 코드가 개수 배지(주황 동그라미)를 얹으므로, 그 자리에 중요한 그림을 두지 마세요.
- 붕어빵은 `bread.png`와 같은 그림체로 그리세요.

#### `start-scene.png`: 시작 화면 배경 전체
- 캔버스: **1024×2210** 세로 그림, **불투명**.
- 화면에 맞추는 방식: 가로를 화면 너비에 맞추고 **아래쪽 기준으로 붙이기** 때문에 **맨 위 390px는 화면에서 잘립니다.**
- 그 위에 올라가는 요소와 이미지 좌표:

  | 영역 | 이미지 좌표 (x, y) | 규칙 |
  |---|---|---|
  | 잘리는 영역 | y 0~390 | 하늘색이나 단색만. 중요한 것을 두지 마세요. |
  | 로고 붕어빵 + 제목 글자 | x 170~855, y 590~1170 | 비워 두세요. 단색이나 은은한 하늘. 제목 글자는 크림색 + 진갈색 외곽선이니 **너무 밝거나 너무 어둡지 않은 중간 톤**이 좋습니다. |
  | 버튼 2개 + 안내 문구 | x 185~840, y 1520~2030 | 버튼이 올라가니 **복잡하고 대비가 강한 그림을 피하세요.** 바닥이나 길 정도가 적당합니다. |
  | 장면(풍경) | y 1300~2210 (아래 약 40%) | 포장마차·골목·눈 오는 밤 같은 **cnation 붕어빵 가게 장면**. 주요 소품은 **버튼의 좌우**(x 0~185, 840~1024)나 버튼 뒤의 낮은 대비 영역에 배치하세요. |

- 그린 뒤 브라우저로 시작 화면을 열어 버튼·글자가 잘 읽히는지 반드시 확인하세요(5장).

### 3-B. 2순위: 손님 캐릭터 (게임의 얼굴)

#### 먼저 캐릭터 표를 만들어 사용자 승인 받기
현재 손님 9종(곰, 코끼리, 독수리, 여우, 사자, 고릴라, 호랑이, 아기곰, 늑대)과 **같은 동물을 같은 옷차림으로 다시 그리지 마세요.** 새 캐릭터를 디자인합니다.
- 처음에는 **4~6종**으로 시작해도 됩니다. 사용자가 원하는 수를 물어보세요.
- 아래 표를 채워 사용자에게 먼저 보여 주고 승인을 받으세요.

| id (영문 소문자) | 캐릭터 콘셉트 | 성격 | 주문 대사 (`{n}`은 개수) | 화난 표정 그릴지 |
|---|---|---|---|---|
| 예) `penguin` | 목도리 두른 배달 펭귄 | 급함 | 붕어빵 {n}! 배달 가야 해서 빨리요! | O |
| … | | | | |

#### 그림 규격
- 파일: `<id>.png`(평소) + `<id>-sad.png`(화난/실망 표정), 모두 `assets/sprites/`에 저장.
- 캔버스: **모든 손님 512×512** 투명 PNG로 통일.
- 표시: 화면 왼쪽 위 **168×166px 상자 안에 비율을 유지해 맞추고, 아래쪽 기준으로 붙여** 표시합니다. 손님은 오른쪽(말풍선·가게 쪽)을 바라보는 게 자연스럽습니다.
- 구도: 가게 카운터 너머로 보이는 **상반신~허리까지.** 캐릭터의 **아래 끝이 캔버스 바닥에 딱 닿게** 그리세요(카운터에 가려지는 느낌). 머리 위 여백은 5~8%.
- 크기감: 손님끼리 키 차이는 조금만 두세요. 캔버스 높이의 80~95% 범위.
- 평소 ↔ 화난 표정: **같은 캔버스, 같은 자세, 같은 위치.** 표정과 작은 효과(땀, 김, 찌푸린 눈썹)만 다르게 그리세요.
- 겨울 장사 배경이니 목도리·모자·장갑 같은 겨울 소품이 어울립니다. 다만 의상 조합은 캐릭터마다 다르게 디자인하세요.

### 3-C. (선택) 3순위: 철판 위 굽기 단계

`bread.png`를 새로 그리면 철판 위 붕어빵과 그림체가 달라집니다. 사용자가 원할 때만 진행하세요.

## 4. 코드 수정 (손님 캐릭터를 바꿀 때만)

이미지 파일만 바꾸면 되는 1순위·3순위는 **코드를 수정하지 마세요.** 손님을 새로 디자인했다면 아래만 고칩니다.

1. `game.js`의 `CUSTOMERS` 배열을 새 캐릭터 표대로 바꿉니다.
   ```js
   const CUSTOMERS = [
     { id: 'penguin', line: '붕어빵 {n}! 배달 가야 해서 빨리요!' },
     { id: 'owl', line: '...', noSad: true },   // 화난 표정 그림이 없으면 noSad: true
   ];
   ```
   - `id`는 파일 이름과 같아야 합니다 (`penguin.png`, `penguin-sad.png`).
   - `{n}` 자리에는 코드가 "2개" 같은 주문 개수를 넣습니다. 대사마다 `{n}`을 꼭 한 번 넣으세요.
   - 화난 표정을 그리지 않은 캐릭터는 `noSad: true`를 붙이세요.
2. 더 이상 쓰지 않는 예전 손님 이미지(`bear.png`, `bear-sad.png` 등)는 **삭제**합니다.
3. 다른 로직(손님 대기 시간, 팁 등)은 건드리지 마세요.

```bash
ids = re.findall(r"id: '([a-z0-9_-]+)'", open('game.js').read())
for i in ids:
  spec[f'{i}.png'] = (512, 512, True)
  if os.path.exists(S + f'{i}-sad.png'): spec[f'{i}-sad.png'] = (512, 512, True)
ok = True
for f, (w, h, alpha) in spec.items():
  if not os.path.exists(S + f): print('❌ 없음', f); ok = False; continue
  im = Image.open(S + f)
  msg = []
  size = im.size
  im = im.convert('RGBA')  # 팔레트(P) 방식 PNG의 투명도도 함께 판정

  if size != (w, h): msg.append(f'크기 {size} → {w}x{h} 이어야 함')
  has_alpha = im.getchannel('A').getextrema()[0] < 255
  if alpha and not has_alpha: msg.append('투명 배경이 아님')
  if not alpha and has_alpha: msg.append('투명 부분이 있으면 안 됨')
  kb = os.path.getsize(S + f) // 1024
  if kb > 400: msg.append(f'용량 {kb}KB (400KB 이하로 압축)')
  print(('❌ ' if msg else '✅ ') + f, '; '.join(msg)); ok &= not msg
for a, b in [(f'bag{i}.png', 'bag0.png') for i in range(1, 4)] + [(f'{i}-sad.png', f'{i}.png') for i in ids]:
  if os.path.exists(S + a) and os.path.exists(S + b) and Image.open(S + a).size != Image.open(S + b).size:
    print('❌ 캔버스 불일치', a, b); ok = False
print('\n전체 통과' if ok else '\n수정 필요')
EOF
```
